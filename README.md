# 🌦 Weather Dashboard Pro

A modern weather application built using HTML, CSS, and JavaScript that fetches live weather information using REST APIs.

## Features

- Real-time Weather Data
- Search by City Name
- Async/Await
- Fetch API
- Error Handling
- JSON Parsing
- Dynamic DOM Rendering
- Responsive Design
- Glassmorphism UI

## Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## Learning Outcomes

- REST API Integration
- Async JavaScript
- Fetch API
- JSON Processing
- Error Handling
- Dynamic DOM Manipulation
